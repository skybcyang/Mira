# 11 号画布布局验收

- 日期：2026-08-25
- Board：`board-showcase-11-coffee-opening`
- 范围：高密度流程图投影、静态布局、初始视口与响应式可读性
- 不包含：内容质量评审、模型输出质量与领域对象变更

## 结论

11 号“从筹备到开业：咖啡店决策画布”保持 53 张 Card 和 35 个 Transformation，按 A-G 阶段从左到右排布。桌面视口中节点边界零重叠；最终汇总 Transformation 的 52 个来源通过聚合节点表达，主流程只保留一条到目标 Card 的边，避免大量来源边穿过卡片。

该改动只作用于画布投影和首次聚焦。Board 中的来源顺序、Transformation、目标 Card、版本和 Run 数据都没有被压缩或改写。

## 可复核约束

- seed 的列间距为 520，行间距为 300，画布 JSON 与 seed 输出一致。
- 最终汇总目标位于 `x=6240, y=900`，不进入上方阶段卡片的节点边界。
- 来源数达到 13 时，投影生成一个 `junction` 节点、一条目标边和零条来源边。
- 聚合节点标签包含来源数量，当前最终汇总显示 `52 个来源`。
- 移动端大型画布首次打开时只对最左侧阶段执行 `fitView`，桌面仍按完整画布建立初始视图。
- React Flow `nodeTypes` 在模块级注册，避免交互期间重复注册导致重渲染警告。
