# 顶栏与悬浮工具细化验证

- 日期：2026-09-08；基线：`ced0c67`；分支：`codex/workbench-layout`。
- 用户反馈：参考新设计的 Mira 字样；搜索居中，撤销/重做/设置靠右；左侧改为悬浮功能工具栏并迁入新建；设置增加网格开关。
- 当前规则已同步[体验设计](../design/experience-design.md)、[UI 系统](../design/ui-system.md)与[用户手册](../user/user-guide.md)。本报告补充首版工作台验证，不改写其历史事实。

## 交付范围

左侧采用完整 `mira` 字标，画板选择归入同一定位区；搜索位于对称三列的几何中心。撤销、重做与系统设置常驻右侧，390px 下三项均直接可达。

工具栏浮于画布左侧，距边缘 16px、距顶栏 20px，按内容高度结束；保留收起偏好。新建、多选移入工具栏，后面是画布、灵感池、方法、文件和更多。移动端改为距边缘 12px 的底部悬浮栏。删除重复的画布新建/多选快捷条，沿用原创建、历史与脏草稿保护调用。

系统设置集中提供网格开关、六套外观和原模型设置入口。网格默认显示，以既有本机偏好机制保存 `mira.workbench.v1.grid`，只影响 React Flow 背景线，不修改 Board、视口、吸附或历史。更多保留计划、画布版本与画板管理。

测试只使用原独立临时 workspace `/tmp/mira-workbench-FN1WVE`。写入验证新建专用画板 `board-ccj571mtsb1ttx`，未修改用户正在试用的 50 卡片画板和分组。主 workspace、真实 56300 服务保持不变；最终构建仍由 56311 提供。

实际浏览器记录：

- 1280×800：搜索中心 x=640，与视口中心一致；浮动工具栏 x=16、y=78、宽 84、高 538，收起后宽 54。画布背景延伸至工具栏后方。
- 390×844：工具栏 x=12、y=772、宽 366、高 60，右侧三个顶栏按钮均 44×44；body 无横向溢出，设置面板可关闭。最终构建再次测量通过。
- 网格关闭后背景 display 为 none，刷新保持关闭；开关前后 React Flow 平移/缩放样式逐字相同。收尾恢复默认显示网格。
- 新建只创建一张 Card，焦点进入正文；保存第一份/第二份正文后，从顶栏撤销得到第一份正文 v3，重做得到第二份正文 v4。空白 Card 创建本身沿用原有历史范围，不新增可撤销语义。
- 多选按钮正确切换按下状态并有明确结束入口。系统设置 Escape 返回顶栏设置按钮；进入模型配置前设置 popup 已关闭。临时适配器仍明确显示不支持网页模型设置，未保存模型配置或请求真实模型。
- 主题切换覆盖三方向的浅/深状态，检查主要截图与布局，无横向溢出。没有对所有功能状态逐一进行六主题截图矩阵。
- 发现并修正展开详情下的工具重叠：原选择工具栏 x=58.2，与悬浮栏右边界 100 重合；修正后选择工具栏与 Context dock 均从 x=132 到 464，详情从 x=480 开始。保留画布视口，通过可用宽度和局部滚动避让。
- 最终构建浏览器 warning/error 日志为空；恢复默认浏览器尺寸，保留预览。
