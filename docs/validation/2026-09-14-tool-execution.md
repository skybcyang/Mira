## 产品命题

输出风格、单项 Skill、工具选择是独立设置。Skill 的冻结文本进入普通模型请求，必需工具依赖不自动授权。连接发现、项目启用、本步绑定互相独立。MCP/已审阅脚本用于生成前或模型按需，后检查只由检查器执行；临时 Python 先审阅实际代码。所有执行仍使用同一 Run、冻结来源、目标基线、CAS/Candidate 和有限预算。完整规则见[执行契约](../specs/tool-execution.md)。

## 实现正确性

- `node-mcp-client.test.js` 通过真实本地 HTTP/SSE 与 stdio 子进程验证握手、分页、目录变化、认证/重定向失败、响应上限、取消、超时、session 清理与未知结果不重放。发现不调用业务工具；同名工具由稳定连接身份区分。
- `openai-compatible-adapter.test.js` 通过真实本地 HTTP 服务完成 tool_call_id 往返，覆盖未知工具/坏 JSON/重复 ID、整批预检、轮数/次数、超限、超时、取消及确定失败与未知结果的区别。Kimi 所需 reasoning 协议字段只留当次内存，不存入 Run；这不是线上 Kimi 模型实测。
- `tool-run-integration.test.js` 使用真实临时文件系统与应用路由验证 Run 前拒绝缺能力/Skill 依赖、冻结工具配置、逐次审批、旧批准失效、方法待绑定、人工 Head 变动进入 Candidate、附件省略与秘密排除。`tool-security.test.js` 覆盖 schema 复杂度、参数边界、一次审批、冻结环境、后检查预算、写入失败停止等。
- 关闭宿主先拒绝仍在准备的 Run；取消后模型即使先返回，也保留待中断身份到终态持久化。能力 HTTP 断开会透传取消，主工作区写锁在请求排空后释放。指导依赖拒绝非数组输入并复制调用方数组，避免保存后被别名修改。
- 参数结构保留合法参数名（如 token 的类型声明），同时拒绝 default/examples/const/enum 携带真实认证数据。方法去掉机器绑定、参数、URL 和批准；Board/Checkpoint 副本要求重新绑定外部能力。配置、凭据、脚本目录不进入可移植包，历史附件明确标记省略。

独立切片使用各自 worktree 和提交，主 Agent 按依赖集成，再由另一 Agent 对最终交叉路径复查。复查发现并修复了关闭竞态、HTTP 取消遗漏、凭据跨目的地、schema 示例秘密、未预留后检查预算等问题；回归先复现再修正。
