# 2026-09-10 开源准备验证

本报告记录首次 MIT 源码开源准备，不代表仓库已经公开或桌面版已经正式发布。产品语义和应用运行代码未改动；测试中对真实画板文件的依赖替换为最小布局夹具。

## 已准备

- 根目录 MIT License、两个 package manifest 的许可信息、贡献指南、安全反馈流程、Issue/PR 模板、路线图。
- Linux/macOS CI、全历史密钥扫描、工作区数据跟踪拦截、Dependabot 更新配置及 `CI required` 汇总检查。
- 内部桌面打包只允许 private 仓库执行，避免开源首个 push 自动暴露未签名 Actions 产物。
- 673 条带版本的依赖许可证记录与生产依赖的原始许可证文本；清单不含本机安装路径。包内版权声明保持原文。
- 当前运行数据、原型、第三方参考和开发归档只在隔离分支取消跟踪，原始工作区与私有 Git 历史保留。公开候选目录由 Git tree 导出，未复制旧 `.git`。
- README 保持产品介绍，已有新手教程、四种不同结构的场景截图与可导入示例继续保留。

## 安全审计与工具链

Gitleaks 8.30.1 的官方二进制经过发布方 SHA-256 校验。旧私仓以 `--log-opts=--all --redact=100` 扫描所有本地可达引用，扫描器处理了 200 个含可扫描差异的提交，报告无命中。这不证明旧历史中的个人数据可以公开，因此仍使用新历史发布。

更新 Vite 至 6.4.3、Vitest 至 4.1.11、React 插件至 4.7.0，以及 esbuild；将旧 tar/tmp 解析到有修复的版本。Electron node-gyp 保持原提交，固定为 codeload 归档 URL，解决 pnpm 9 将 GitHub 依赖解析为 SSH 后安装失败的问题。

`pnpm audit` 从 24 项降至 2 项高危，未宣称全量审计通过。剩余为 DMG 开发工具链中的 `image-size@0.7.5` 两项解析拒绝服务公告，上游未提供修复版本，影响范围和约束见 [SECURITY.md](../../SECURITY.md)。`pnpm audit --prod` 为 0 项。审计只是当日数据库结果，不是无漏洞保证。
