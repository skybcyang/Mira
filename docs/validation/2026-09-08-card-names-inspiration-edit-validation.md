# 独立卡片名称与灵感编辑验证

日期：2026-09-08。基线：`codex/workbench-layout` 的 `f3683a1`；独立分支：`codex/card-names-inspiration-edit`。

## 产品结果与可发现性

- 卡片更多菜单提供重命名，详情顶部可独立保存名称；清空回退默认标题。正文、版本、Head 与会话历史不受改名影响。
- 名称随复制、搜索、来源呈现及导入导出保留；旧卡缺失字段无需迁移。
- 灵感全文底部提供编辑，复用记录表单；正文变化追加不可变 human 版本，仅标签变化不追加版本。
- 已选旧版本保持不变并提示池中已有新版；既有画板副本不随池编辑变化。
- 名称、正文和标签草稿纳入离开保护；冲突保留输入，需要明确核对或载入最新内容。

## 实现正确性

- 名称请求在 Board 写锁内比较 baseName；灵感请求在池串行队列中比较 Head 与单调更新时间。错误不产生半写。
- 新增失败测试后实现：独立名称写回、版本不变、名称冲突；池不可变版本、标签变化、同毫秒并发与原子保存失败；Store 改名和正文迟到响应交错、切换画板、冲突刷新及重试通知清理。
- 真实 Node Host / HTTP 集成使用临时 workspace：验证 409/404、历史池版本仍能创建快照、旧 Board Card 完全不变、名称持久化、导出导入及完整备份。
- `pnpm test`：134 文件、1495 测试通过（18:21:36 开始，6.09 秒）。
- `pnpm exec tsc --noEmit`、`pnpm build`、`pnpm build:bridge`、`git diff --check` 通过。

## 真实浏览器与产物质量

- 独立预览使用 `/tmp/mira-names-preview-InvgFL`、端口 56312；测试未写真实用户 workspace，未替换此前安装的 macOS app。
- 1280×900：菜单重命名聚焦名称输入，独立名称与正文标题不同；改名后卡片仍为 v1。关闭脏详情出现确认，保留编辑能继续保存。
- 名称冲突：通过同一临时服务模拟另一窗口写入，旧草稿保存被拒绝，显示最新名称且保留草稿；核对后可保存。
- 灵感：记录、全文、加入已选、编辑、保存、返回结果均通过；编辑后的列表明确显示已选旧版本。只修改服务端标签也会使旧编辑基线冲突；草稿仍可复制，明确载入后恢复最新正文和标签。
- 390×844：名称输入高度 44px，灵感保存按钮高度 44px、底边 834.5px，全文编辑入口可达；页面 scrollWidth 为 390px。名称和灵感编辑无横向溢出或操作遮挡。
- 灵感编辑 Escape 显示同层草稿离开确认，继续编辑保留正文。重新启动预览后名称和灵感修改仍存在；清空名称恢复正文首行，CardVersion 仍为 v1。
- 刷新最终构建后浏览器 warning/error 日志为空；故意触发的冲突流程由预期 HTTP 409 与界面提示覆盖。验证结束恢复临时 viewport。
