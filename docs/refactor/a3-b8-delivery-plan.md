## B5 真实模型质量计划

模型继续优先使用用户指定的 Kimi，通过现有 adapter 与安全凭据配置。旧对话提供的密钥不进入文件、命令日志、截图或证据包。执行前记录实际模型 ID、供应商、输入限制和失败信息，不把“kimi”当作一个固定模型版本。

首批采用六组明确可使用的材料，其中至少两组为不同来源的实际文章/公开报告；项目自有设计文档可作真实内部材料，合成访谈/字幕必须标为演示，不能替代真实材料覆盖。使用第三方材料前记录来源与可保存范围，证据不无条件收录受限制的完整文档。

| 材料组 | 要验证的任务 | 对照与复核重点 |
| --- | --- | --- |
| 网页长文 A | 按用户问题提取主张与依据 | 无指导/精读；原句与推断是否分开，页面完整性 |
| 不同来源文章 B | 换材料复用同一精读方法 | 新材料/旧方法冻结版本，B7 重新选择要求 |
| 文本 PDF 报告 | 选择页段后做证据核对 | 无指导/证据对照；页码、表格阅读顺序、限定条件 |
| 项目设计与反馈 | 根据明确反馈生成修订稿 | 无指导/修订；人工约束与未要求内容是否保留 |
| 访谈或标注字幕 | 同一材料按不同要求动态提取 | 数量、遗漏、重复、过度拆分、实际定位；不称视频理解 |
| 已拆分且人工修改的清单 | 重跑、对照并采用到旧卡 | 错配/合并/拆分/未出现项、人工改动保护、修改成本 |

先完成离线与故障测试，再按显式选定用例运行真实模型。每个无指导/有指导对照共享材料、模型与用户要求，只改变指导；初轮每组一次，不自动循环刷分或失败重试付费调用。需要复测时记录原因和新增运行次数。B3/B4 各至少在两份不同材料复用；可交叉复用材料组，不用重复调用凑数量。

评审记录每条可核对主张的来源位置、是否获得支持、是否漏掉限定条件、原文/推断是否区分，以及未满足的用户要求。另记输出字数、条目数、重复项、人工修改字符数与修改用时；机械统计与人工判断分别列出。检查程序只能标出可核对线索，不自动判定结论真伪。

通过标准：零未标明的虚构引用/页码；关键用户约束逐条满足或明确无法满足；用户选定范围外的正文在真实 adapter 入参中不存在；B6 结构完整且人工可以纠正条目。样本中存在质量失败就保留原始结果、标记失败、修改指导再增加新运行，不覆盖旧证据。只有有/无指导的实际比较支持时才声称 skill 有改善，不要求每项都改善才能交付可选工具。

输出为新的验证报告与可导入示例证据，记录材料性质、provider/model、Run、输入/输出、指导版本、选择范围、人工判断与限制；保留既有 2026-09-12 报告不回写结论。若资料无法公开，输出匿名统计和复现步骤，保留原始材料在用户授权的私有位置。
