## 0. 当前决策与重启条件

2026-09-06，用户确认现在不做推导链折叠，先实际使用已交付的卡片颜色与显式分组。
本文件保留已讨论的方案和未决问题，不据此新增代码、持久对象或执行能力。

暂缓原因：首尾原位的收起只减少过程内容的视觉噪声，不缩短长链，也不解决大量平移；
同时需要处理隐藏选择、分组操作、搜索定位、撤销与 Run/Candidate 可达性。当前收益尚未
通过真实课题验证，不把这些兼容成本作为立即实现的理由。

以后由用户根据实际使用重新决定是否启动：

- 分组、颜色和命名已足够支持查找和整理：继续暂缓。
- 中间推导反复干扰阅读，但必须保留追溯：重新评估本方案的收起价值。
- 主要问题是链太长或画布太散：另行讨论收紧布局，不用原位折叠代替空间整理。

重启前还须确认与分组的兼容边界：全部真实成员参与组框计算；隐藏成员如何参与整组
移动、选择与复制；跨组链是否允许收起；成员调整及撤销如何重新校验或展开相关过程。
这些是待决问题，不把本次审视中的建议自动升级为产品规则。

## 1. 产品结果

用户已经理解一段推导后，可以只看原材料和当前成果，需要追溯时再打开过程。折叠不是
删除、归档、复制或保存方法；不改变任何正文、Head、Version、来源或执行顺序。

示例：材料 A 经三次转化产生 B、C、成果 D。收起后仍显示完整 A 和 D，中间用一个
`3 个步骤 / 2 张中间卡`的折叠标记表示原路径。箭头是现有 Transformation 的显示投影，
不会创建新的卡间直连。展开恢复原有的全部 Card 与转化块。

**首版建议不自动收紧首尾距离。** 折叠减少过程内容与连线的视觉噪声，但不把宽链自动变短。
两端位置与原手工布局保持稳定；自动压缩会牵动共享端点、其他分支及布局撤销，留作单独
讨论。本设计的确认项 D2 专门覆盖这项取舍，不用紧凑示意掩盖真实布局限制。

## 2. 范围与边界

- 一段有效范围具有明确的首 Card、尾 Card 和唯一有向路径；至少 2 个 Transformation，即至少 1 张中间 Card。
- 首版只接受每步单来源的线性段。多来源汇入、分叉、循环、多条到达路径不被猜测为同一段。
- 中间 Card 必须恰好由段内上一条 Transformation 产生、只被下一条消费；不能被段外步骤引用。首尾可与段外连接，但必须留在画布上。
- 遇到共享节点、分叉或汇合时，以该节点为可见边界；不能把另一条链依赖的节点收走。
- 多个折叠可以并存，并可共享一个可见端点；不允许内部交叠或嵌套。覆盖已有折叠时提示先展开，而非自动合并。
- PlanDraft 不参与折叠；存在计划绑定草稿时先完成或取消草稿，避免临时输入连接被隐藏。
- 只有首尾相邻的一步关系不提供折叠，因为没有中间 Card 可隐藏。

## 3. 创建折叠

### 3.1 主入口：选择首尾

1. 用户按现有多选方式选中两张 Card；选择工具栏显示 `FoldHorizontal` 图标，tooltip/可访问名称为`收起中间过程`。
2. 根据有向关系确定首尾，不根据点击先后交换原有来源顺序。必须恰好找到一段合法路径。
3. 点击后进入轻量范围预览：首尾保持正常强调，中间节点降低强调并显示范围轮廓；还没有隐藏或写入。
4. 预览只显示起点、终点、步骤数和中间卡数，以及`取消`、`收起`。用户确认后完成折叠，焦点进入折叠标记。
5. 取消/Esc 保留原选择、视口和节点；不创建或运行任何对象。

选择工具栏里的现有复制/删除与折叠是并列命令，不用删除图标表示收起。若路径不合法，
入口通过可访问禁用态和短原因说明边界，不默默选择另一段。

### 3.2 快捷入口：从成果回溯

尾 Card 的菜单提供同一个`收起中间过程`命令，沿唯一上游链找到最近的有效边界，并进入
同一范围预览。用户仍看到准确首尾；不能一点击就无提示收起整张画板的祖先。
若发现歧义或不足两步，使用同一拒绝原因。首版不新增全局快捷键。

## 4. 折叠标记

标记是视图控件，不是 Card、Transformation 或可运行子图。无正文、版本号、连接 handle、
重命名或独立运行按钮；不能作为模型来源、复制对象或被 Delete 删除。

- 约 232px 宽、88px 高的紧凑面，4px 圆角、低强调 surface，无 Card 阴影；不使用 PlanDraft 的虚线样式。
- 标题行：`3 个步骤`与常显 `UnfoldHorizontal` 图标；副行：`2 张中间卡`。
- 普通状态不显示夸张成功色；有运行、Candidate、失败、stale 时显示图标与短文字，不能只依赖颜色。
- 点击数量/主体打开步骤清单；点击展开图标直接恢复整段。两个命中区独立，不嵌套 button。
- 选中/聚焦标记不改变 selectedCardIds 或 Context dock 的来源；标记焦点下的 Card 复制、删除、移动快捷键不执行。

### 4.1 步骤清单

桌面使用约 320px 宽的锚定 popover，靠近视口边缘时自动避让。每行展示：序号、成果目标、
当前状态、`定位步骤`图标。列表按真实路径顺序排列；底部只有`展开全部`。

点击某一步会先展开对应折叠，再定位原 Transformation 并进入现有关系详情；点击 Run 或
Candidate 状态则进入已有运行/比较入口。不在折叠清单内复制一套停止、采用或丢弃流程。
首次只支持整段展开，不做逐层揭示或嵌套折叠。

## 5. 状态可达性

| 状态 | 折叠呈现 | 操作 |
| --- | --- | --- |
| 有未处理 Candidate | `待比较 N`，最高决策优先级 | 直接到原 Run/比较视图，并展开对应段 |
| 有活动 Run | `生成中 N` | 进入原运行视图，停止继续复用已有命令 |
| 失败或停止 | `失败 N`或`已停止` | 定位对应步骤/Run |
| stale | `来源已变化 N` | 查看哪些步骤需要更新，不自动运行 |
| 普通 | 仅步骤/中间卡数量 | 清单与展开 |

状态从原 Transformation/Run 投影计算，按 Run ID 去重；尾 Card 的状态仍正常显示。
同时有多类状态时展示最高优先级及额外数量，清单保留全部状态。状态读取失败显示
`状态暂不可用`，不能用无提示的正常态代替。任何状态变化不自动展开整图或抢走焦点。

折叠不阻止原有`运行到这里`检查隐藏步骤；遇到 Candidate、失败或来源不可用仍按原规则
停下。折叠本身和展开本身均为零 Run。正在编辑的中间卡必须先经过现有 dirty guard；
存在将被隐藏的已选 Card 时先要求取消该选择，不悄悄改变模型输入。

## 6. 布局与移动

- 首尾 Card 的位置、尺寸、缩放及其他链完全不变，不触发 fitView 或写回 viewport。
- 标记优先放在隐藏段原占用区域中靠近路径中点的位置，连接首尾；至少避让可见 Card/转化块 24px。
- 原路径太窄时尝试近旁的空位和折线连接；没有可读空位时拒绝折叠并保留原状，不覆盖其他内容。
- 中间节点的原坐标不删除。展开时显示最新 Board 中的实际坐标，不用创建折叠时的旧位置覆盖后续修改。
- 拖动可见首尾仍只移动该 Card，标记重算位置；不暗中移动隐藏中间卡。要搬动整条链，应先展开再使用现有多选。
- 当前画板`全选`会先展开所有折叠，再按现有规则选择全部 Card，避免产生不可见的批量操作对象。
- 折叠与展开不进入 CanvasHistory；正文或 Card 移动仍沿用现有历史规则。

## 7. 定位、结构变化与记忆

- 搜索仍检索全部 Card 当前 Head。仅在用户确认某个隐藏结果时展开对应段，再用现有可读定位；输入查询或取消搜索不展开。
- 从版本、Run、方法出处等入口定位隐藏对象，遵循同一`先展开后定位`路径；不解除其他无关折叠。
- 来源或正文版本变化只更新状态；不解除折叠。结构变化导致路径失效、出现共享中间节点或成员删除时，仅解除受影响段并提示`推导结构已变化，已展开对应过程`。
- 一个页面会话内按 Board 记住折叠；切换再返回会重新校验路径。刷新或重开页面默认展开。
- 首版不新增持久数据对象/API；不写入 BoardArtifact、MiraBackup 或 BoardCheckpoint，不承诺跨设备同步折叠。

## 8. 响应式与可访问性

- Desktop/Compact 仍是同一可平移画布，不为适配窗口重新排列或缩小首尾 Card。
- 390px 下首尾可能不同时在视口内，保持可读缩放并允许平移；不能为了同时容纳首尾把字缩到不可读。
- 窄屏的范围确认与步骤清单使用同层 sheet，固定底部命令，计入 safe-area，控件命中至少 44px；不嵌套第二个 modal。
- 未展开清单时，展开图标常显，不依赖 hover。数量和关键状态具有可访问名称。
- Enter/Space 激活原生按钮，Esc 关闭当前预览/清单并返回触发处；不把 Esc 当作删除折叠。
- 展开后焦点交给原步骤/定位目标；折叠后 aria-live 播报`已收起 3 个步骤，首尾卡片保留`。
- 动画只淡出/恢复中间投影并更新连接，约 160–200ms；尊重 reduced-motion，不移动端点。

## 9. 确认项

| ID | 建议首版基线 | 影响 |
| --- | --- | --- |
| D1 | 唯一、单来源、无共享中间节点的线性段 | 分叉/汇合停在可见边界，不猜测范围 |
| D2 | 首尾原位，不自动拉近距离 | 减少视觉噪声，不承诺缩短整条链宽度；收紧布局另议 |
| D3 | 两端选择为主入口，成果菜单为快捷入口，先预览范围 | 少误收起，不改现有来源选择语义 |
| D4 | 标记可打开清单，也可整段展开；状态入口先展开后定位 | 不隐藏 Candidate，不另造运行流程；逐步展开暂缓 |
| D5 | 页面会话内记忆，刷新展开 | 无数据格式/API/备份迁移；跨重启记忆暂缓 |

只有用户明确重启需求并重新确认上述细节后，才同步权威产品/规格/UX/UI 并进入实现。当前交互示意只用于确认
端点保留、标记、清单和状态处理，不等于生产实现或真实画布几何验收。
