# 使用步骤能力

入口是“系统设置 → 能力管理”和步骤详情中的“输出要求 / 本步指导 / 工具能力”。完整边界由[工具执行契约](../specs/tool-execution.md)定义。

## 输出与 Skill

新步骤默认采用“卡片简洁”。在能力管理中修改项目默认，只影响之后创建的步骤；已有步骤在“输出要求”里调整。风格文本随步骤冻结，字符上限与结构由程序另行检查。

每步明确选择一项指导，或不使用。自定义/导入文本不会安装程序，普通模型（包括支持当前接口的 Kimi）会收到本次冻结指导。指导可以声明必需和可选工具 ID；在工具的身份详情查到 ID 后填写。必需依赖未选齐时可以保存计划，但不能运行。

## 内置工具

在“工具能力”添加工具，填写参数、选调用方式并保存。来源范围复用步骤的全文/选区设置。

| 工具 | 示例参数 | 用途 |
| --- | --- | --- |
| 材料检索 | `{"query":"限制"}` | 在本次来源中找包含指定文字的行 |
| 数字运算 | `{"operation":"sum","values":[12,30]}` | 确定性计算 |
| CSV 摘要 | `{"sourceIndex":0}` | 汇总第一份来源中的 CSV |
| 网页读取 | `{"url":"https://example.com/"}` | 还需将精确网址加入本步允许范围；跳转地址也须明确列出 |
| 正文检查 | `{"maxCharacters":300,"contains":["结论"]}` | 生成后检查，未通过保留正文与诊断 |

“生成前”会按同阶段列表顺序执行；“模型按需”让模型在所选集合内决定是否使用。未调用不会伪造记录。当前后检查只开放正文检查器。

已有成果在“运行到这里”中仍按来源是否变化判断是否保留。修改设置后用“仅重跑这一步”尝试当前配置，不自动重跑上游。

## MCP

在能力管理选择“MCP 连接与工具”，填远程 HTTP 地址或本地程序、参数、目录，再“测试连接并保存”。本地程序必须已安装；连接测试可能启动它，但不会调用业务工具。

发现目录后逐项在项目启用，再到步骤中选择并绑定参数。默认每次执行前审阅完整请求；只有明确核对过的工具才能标为只读。模型不能修改已绑定的 MCP 参数。

凭据只保留当前宿主会话，重启需要重填；更换连接目的地时也需明确重填或清空。不要把凭据放进参数、地址、指导或代码。schema 不受支持或连接变化时重新核对目录和步骤绑定。

## Python

先启动本机 Docker 的 Linux 容器环境。在“Python 环境与脚本”明确准备镜像，依赖每行填写固定版本（如 `packaging==24.2`）；准备会联网下载，普通 Run 不下载或安装。

登记脚本时填写完整代码与参数结构，选择固定环境，先测试再保存。测试来源为空，不创建 Card 或 Run。下面是只使用输入副本的最小示例：

```python
import json, sys
value = json.load(sys.stdin)
print(json.dumps({"text": "收到 %d 份来源" % len(value["sources"])}, ensure_ascii=False))
```

保存追加脚本版本，项目启用后才能在步骤中选择。修改测试参数不产生脚本版本。脚本返回的 PNG/CSV/TXT 先预览，再明确下载。

临时代码需要在本步单独开启。模型提出完整代码后，运行暂停等待审阅；批准仅执行这一份代码和冻结环境。拒绝或停止结束等待，旧批准不能复用。

## 运行与复用

运行记录分别展示冻结设置、实际调用与检查诊断。调用结果不确定时先核对外部目的地，避免重复执行。人工正文在运行中变化时仍进入 Candidate 比较。

方法只携带能力需求，应用后重新绑定；数据包不安装 MCP 连接、脚本、凭据或环境。历史附件不随可移植包携带，所需文件请另行下载保存。
